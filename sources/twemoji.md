## What is there

- Kinds: icon, sprite
- Styles: cartoon
- Approx count: ~4,000
- Formats: svg, png
- Access: github. no key; SVG and 72x72 PNG per emoji code point; Iconify prefix "twemoji". Docs: https://github.com/jdecked/twemoji

## How to search and download

- `curl -s https://api.iconify.design/twemoji/mushroom.svg -o mushroom.svg` or take `assets/svg/<codepoint>.svg` from the repo.

## Good for / not for

- Good for: Cheerful flat placeholder or final art for items, food, animals, faces, weather, UI reactions.
- Not for: Games without a credits/about line.

## Gotchas

- Graphics are CC BY 4.0 (code MIT). The project accepts credit in an About screen, footer or README.
- Files are named by Unicode code point (e.g. 1f344.svg = mushroom).
- Alternatives via Iconify: Noto Emoji (Apache-2.0, no credit), Fluent Emoji (MIT). OpenMoji is CC BY-SA (share-alike): avoid unless the user accepts SA.
