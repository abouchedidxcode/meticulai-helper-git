# BeepBox (and its fork JummBox)

Short chiptune/synth loops and jingles made by the user (or written by an agent as a song URL, then exported).

Site: https://www.beepbox.co

## What is there

- Kinds: music
- Styles: pixel, cartoon, any
- Approx count: not stated
- Formats: wav, mp3, mid, json
- Access: site. browser app, no account; the whole song is stored in the page URL; JummBox (https://jummb.us) is a fork with more features and the same ownership statement. Docs: https://github.com/johnnesky/beepbox

## How to search and download

- Open https://www.beepbox.co (or https://jummb.us for JummBox), compose, copy the URL to save.
- File > Export: wav or mp3 for the game, midi or json for other tools.

## Good for / not for

- Good for: Short chiptune/synth loops and jingles made by the user (or written by an agent as a song URL, then exported).
- Not for: Realistic instruments or vocals; very long scores.

## Gotchas

- Only your ORIGINAL songs are yours. Songs other people shared as BeepBox links belong to them: do not use someone else's URL without their licence.
- Save the song URL in the repo (e.g. assets/music/SOURCE.md) so it can be edited later.
- Export from the File menu; prefer ogg/mp3 for the web (convert the wav with ffmpeg if needed).
