# ShareTextures

Realistic tiling materials for calm games (architecture, interiors, nature walks).

- Site: https://www.sharetextures.com
- Licence: **LicenseRef-ShareTextures-custom-CC0**. Credit required: **no**. Commercial games: **yes**. AI-generated: **no**.
- What: material, model; styles: realistic; about 1700 items; formats: jpg, png.
- Can an agent fetch it? **manual** (api = use the API; direct = fetch single files by URL; allowed = small polite fetches; manual = the user downloads by hand).

## How to search and download

- The user downloads by hand from https://www.sharetextures.com (their terms forbid automated downloads). Not for violent games.

## Good for / not for

- Good for: Realistic tiling materials for calm games (architecture, interiors, nature walks).
- Not for: Violent games (their terms forbid violent content), automated pipelines, re-sharing the files.

## Gotchas

- Not real CC0: it adds rules. No redistribution of the files, no automated downloads, no violent content. Combat or shooter games: use Poly Haven or ambientCG instead.
