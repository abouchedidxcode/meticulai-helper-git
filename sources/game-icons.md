## What is there

- Kinds: icon
- Styles: stylized, any
- Approx count: ~4,100
- Formats: svg, png
- Access: github. no key; SVGs in the GitHub repo, one folder per author; also via Iconify (prefix game-icons); site has an editor for colour/background and PNG export. Docs: https://github.com/game-icons/icons

## How to search and download

- Search on https://game-icons.net or with Iconify: `curl -s "https://api.iconify.design/search?query=potion&prefix=game-icons&limit=32"`.
- Raw SVG from GitHub (tested, HTTP 200): `https://raw.githubusercontent.com/game-icons/icons/master/lorc/broadsword.svg` (path is author/name).
- Add "Icons made by {author}" for every author used to the credits screen.

## Good for / not for

- Good for: Fantasy/RPG/strategy icons: weapons, spells, items, resources, status effects, skills, cards, map markers.
- Not for: Games that cannot show a credits line; pixel-art styles (these are flat silhouettes).

## Gotchas

- Credit the AUTHOR of each icon (Lorc, Delapouite, ...), not just the site. The author is the GitHub folder name.
- A few contributors (e.g. Viscious Speed, Zeromancer) are CC0; the rest are CC BY 3.0.
- Silhouettes are single-colour on 512x512: recolour with CSS fill or the site editor.
