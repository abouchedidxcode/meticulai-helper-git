## How to search and download

- Search https://fontawesome.com/search?ic=free or `curl -s https://api.iconify.design/fa7-solid/dragon.svg -o dragon.svg`; keep an attribution line in credits.

## Good for / not for

- Good for: Familiar UI and brand icons (social links, controller, volume, gear).
- Not for: Pro icons (paid; not in the Free set).

## Gotchas

- Three licences in one download: icons (SVG/JS) CC BY 4.0, font files OFL 1.1, code MIT.
- Attribution is required, but Font Awesome says the comments already embedded in the downloaded files are enough; keep those comments (do not strip them in minified SVGs) or add a credit line.
- Only the Free set; icons marked Pro need a paid plan. Brand icons are trademarks: use only to refer to the brand.
