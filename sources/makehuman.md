# MakeHuman (exported characters)

Realistic human base meshes with a skeleton, to rig/animate (e.g. with Mixamo) and export to glTF via Blender.

Site: https://static.makehumancommunity.org/makehuman.html

- Kinds: model
- Styles: realistic
- Approx count: not stated
- Formats: fbx, obj, dae, mhx2
- Access: site. free desktop app (AGPL); also the MPFB add-on for Blender; output with bundled assets is CC0. Docs: https://static.makehumancommunity.org/makehuman/faq/can_i_sell_models_created_with_makehuman.html

## How to search and download

- User installs MakeHuman (or MPFB in Blender), designs the character, exports FBX/OBJ; import into Blender, reduce polygons, export .glb.

## Good for / not for

- Good for: Realistic human base meshes with a skeleton, to rig/animate (e.g. with Mixamo) and export to glTF via Blender.
- Not for: Stylised/cartoon characters; agent-only workflows (GUI app).

## Gotchas

- Only the assets bundled with MakeHuman are CC0. Community assets (clothes, hair) downloaded separately can be CC BY: check each one.
- Exports are high-poly: decimate in Blender and export glb for the browser.
- The app itself is AGPL; that does not affect your exported models.
