Sci-fi panels, stylized and hand-painted-looking tiling materials, plus realistic ones.

- Site: https://3dtextures.me
- Licence: **CC0-1.0**. Credit required: **no**. Commercial games: **yes**. AI-generated: **no**.
- What: material; styles: realistic, stylized; about 1300 items; formats: jpg, png, sbsar.
- Can an agent fetch it? **manual** (api = use the API; direct = fetch single files by URL; allowed = small polite fetches; manual = the user downloads by hand).

## How to search and download

- The user searches https://3dtextures.me (or its Interactive Material Library) and downloads one texture at a time.

## Good for / not for

- Good for: Sci-fi panels, stylized and hand-painted-looking tiling materials, plus realistic ones.
- Not for: Automated pipelines.

## Gotchas

- Downloads go through third-party file hosts per texture; the user fetches them.
- Some downloads are .sbsar (Substance) only: needs Substance or Material Maker to bake.
