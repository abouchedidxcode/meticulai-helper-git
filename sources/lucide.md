## What is there

- Kinds: icon
- Styles: any
- Approx count: ~2,000
- Formats: svg
- Access: github. no key; npm "lucide" / "lucide-static", GitHub SVGs, or Iconify prefix "lucide". Docs: https://lucide.dev/guide/

## How to search and download

- Search on https://lucide.dev/icons or `curl -s "https://api.iconify.design/search?query=volume&prefix=lucide"`; save the SVG via `https://api.iconify.design/lucide/volume-2.svg`.

## Good for / not for

- Good for: Clean line icons for menus, HUD buttons, settings, pause/mute/fullscreen.
- Not for: In-world game art or themed fantasy items.

## Gotchas

- ISC needs the copyright and permission notice kept "in all copies": include Lucide's LICENSE in your third-party notices file. No on-screen credit.
- Icons derived from Feather are listed on the licence page under a separate MIT notice: keep that too.
