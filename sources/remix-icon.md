## What is there

- Kinds: icon
- Styles: any
- Approx count: ~3,200
- Formats: svg, woff2
- Access: github. no key; npm "remixicon" or Iconify prefix "ri" (Iconify still labels it Apache 2.0; upstream changed licence in Jan 2026). Docs: https://github.com/Remix-Design/RemixIcon

## How to search and download

- Search https://remixicon.com or `curl -s https://api.iconify.design/ri/sword-fill.svg -o sword.svg`; read the License file before shipping.

## Good for / not for

- Good for: Neutral line + fill UI icons inside a game's menus and HUD.
- Not for: Your game's logo or app icon; reselling icons.

## Gotchas

- Since January 2026 it uses its own "Remix Icon License v1.0", no longer Apache 2.0. Commercial use in a game is allowed; attribution optional.
- Forbidden: using an icon (even modified) as a logo, brand mark or app icon; selling icons as a pack; making a competing icon set.
- Brand icons (GitHub, Discord...) only to link to that brand.
- Version mismatch on 2026-11-14: the npm package remixicon 4.9.1 and Iconify still say Apache-2.0, the GitHub License file says Remix Icon License v1.0. Follow the stricter custom licence (no logo/app-icon use) to be safe.
