## How to search and download

- Browse packs at https://99sounds.org (categories: sound effects, samples).
- User downloads one pack zip; copy only the files you need into the game and convert to ogg.

## Good for / not for

- Good for: Cinematic hits, whooshes, drones, ambiences, synth one-shots and glitch sounds in polished packs.
- Not for: Fine-grained search for one specific sound (it is pack-based); re-sharing the raw files.

## Gotchas

- Same licence for all packs on the site (not CC): commercial use OK, credit optional, but no redistribution of the raw files, even for free.
- If a pack download asks for an email, the user does it; the agent must not sign up.
- Some packs include plugins/instruments (not needed for games); use only the audio files.
