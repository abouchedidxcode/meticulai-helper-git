- Kinds: icon
- Styles: any

- Formats: svg
- Access: github. no key; npm "heroicons" or Iconify prefix "heroicons". Docs: https://github.com/tailwindlabs/heroicons

## How to search and download

- Copy SVG from https://heroicons.com or `curl -s https://api.iconify.design/heroicons/cog-6-tooth.svg -o settings.svg`.

## Good for / not for

- Good for: Small, consistent UI set (menus, settings, arrows) that pairs with Tailwind-style web UI.
- Not for: Game-themed icons (very few).
