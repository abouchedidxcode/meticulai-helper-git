## How to search and download

- User downloads from the GitHub releases or itch.io page, or opens the web beta linked in the README.
- Compose with the pattern grid, then export wav; convert to ogg.

## Good for / not for

- Good for: Beginner-friendly pattern-based music for games; the user makes loops without music theory.
- Not for: Agent-only workflows (it is a GUI app; no text song format an agent can write easily).

## Gotchas

- The project says songs can be used "for your next game"; no ownership claim over your songs.
- Exports wav and midi only; convert to ogg/mp3 for the web.
- The original Bosca Ceoil (boscaceoil.net) is archived; use Blue.
