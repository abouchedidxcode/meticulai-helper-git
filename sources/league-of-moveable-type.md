Strong display/title fonts (League Gothic, League Spartan, Orbitron, Ostrich Sans, Knewave) for logos and menus.

Site: https://www.theleagueofmoveabletype.com

## What is there

- Kinds: font
- Styles: any
- Approx count: ~18
- Formats: otf, ttf, woff, woff2
- Access: github. no key; each family has a GitHub repo with release zips (count is families, 77 styles). Docs: https://github.com/theleagueof

## How to search and download

- Pick a family on https://www.theleagueofmoveabletype.com; each page links a release zip on GitHub, e.g. https://github.com/theleagueof/league-gothic/releases
- Download the release zip, copy the woff2 (or convert the otf) and OFL.txt into `assets/fonts/`.

## Good for / not for

- Good for: Strong display/title fonts (League Gothic, League Spartan, Orbitron, Ostrich Sans, Knewave) for logos and menus.
- Not for: Large multilingual body text (limited language coverage on some families).

## Gotchas

- OFL: bundle in the game, keep OFL.txt with the files, do not sell the font alone.
- Some families declare Reserved Font Names: if you modify the font (not just subset it), rename it.
