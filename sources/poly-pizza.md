# Poly Pizza

Single low-poly props by many artists (lots from Google Poly and Quaternius); quick placeholders.

- Site: https://poly.pizza
- Licence: **mixed**. Credit required: **yes**. Commercial games: **yes**. AI-generated: **no**.
- What: model; styles: lowpoly, cartoon; about 10000 items; formats: glb, fbx, obj.
- Can an agent fetch it? **manual** (api = use the API; direct = fetch single files by URL; allowed = small polite fetches; manual = the user downloads by hand).
- Checked: 2026-11-14 (partial: API answered 401 without key 2026-11-14; site 403).

## Licence

> Not verified on the original site: it blocks automated readers. Each model page shows its own licence (mostly CC BY, some CC0).

Source: https://poly.pizza

## Credit line

Required. Put this in `my-game/CREDITS.md` and the game's credits screen:

```
"{title}" by {author} ({url}), {license}
```

## How to search and download

- The site and API refuse tools without an account key. Ask the user to search https://poly.pizza, check the licence on the model page, download the GLB and drop it in `my-game/.helper/inbox/` with the page URL.

## Good for / not for

- Good for: Single low-poly props by many artists (lots from Google Poly and Quaternius); quick placeholders.
- Not for: A consistent look across many models (many different artists).

## Gotchas

- Check the licence on each model page; CC BY models need a credit line.
- Partly verified only (site and API answer 403/401 to tools); count is approximate from third-party guides.
- Many models are Quaternius or Kenney re-uploads: prefer the original source.
