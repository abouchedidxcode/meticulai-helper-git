# Starter sounds: credits and licences

Everything in this folder may be used in any game, changed, and shared, with no credit needed: the licence is
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (public domain dedication). Credit is given here anyway.

Sounds made with paid AI sound services are **not** in this folder, on purpose: those services' terms do not allow
sharing the generated files as a collection.

## Made in code (61 sounds, 143 files)

Every sound whose id does not start with `mt-`. Rendered by `tools/sounds/synth.mjs` from the recipes in
`tools/sounds/recipes.json`: oscillators, noise and filters, no recordings and no samples. Original work of the
Meticulai Helper Git kit, dedicated to the public domain (CC0 1.0).

- **Made in code for the game**: synthesised by the game's own audio build. Own work, CC0 1.0.

## If you add a sound to this folder

It needs a written licence that allows sharing the file itself (CC0, or CC BY with the credit line written here), an
entry in `catalog.json`, and a row above. Run `node tools/sounds/test.mjs` afterwards.
