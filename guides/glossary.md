# Glossary

Words the agent may use, in one plain line each.

| Word | What it means |
| --- | --- |
| **Agent** | An AI that can read files and run programs on your computer to do work for you, not just chat. |
| **Asset** | Any file the game uses that isn't code: a picture, texture, 3D model, sound or song. |
| **Browser** | The app you use for websites (Chrome, Safari, Firefox, Edge). Your game runs in it. |
| **Build** | Turning the game's working files into a finished, compact version that runs anywhere. |
| **CC0** | A licence that means "free for anyone to use for anything, no credit needed". The easiest kind of free asset. |
| **Commit** | A saved snapshot of the game's files. The agent makes them often, so any change can be undone. |
| **Deploy** | Putting a built game on the internet so other people can play it. Here it only happens with your yes. |
| **fal** | A paid online service that generates pictures, sounds, music and 3D models with AI. Optional. |
| **Headless** | A browser running invisibly in the background. The agent uses one to test and record your game without opening windows. |
| **Key** | A secret password that lets a program use a paid service (like fal) on your account. Never paste it into a chat. |
| **Localhost** | Your own computer, acting as a tiny website. A `http://localhost:...` link only works on your computer. |
| **Prompt** | The text you or the agent write to tell an AI what to do. |
| **Repo** (repository) | A project folder that keeps the full history of its changes. This kit is one; so is your game's folder. |
| **Server** | A program that hands out web pages. The agent runs a small one on your computer so your browser can open the game. |
| **Subagent** | A helper agent the main agent starts to do one job, like building the sound or reviewing a recording. |
| **Swarm** | Several subagents working at the same time on different parts of the game. |
| **Worktree** | A separate copy of the game's folder for one helper, so helpers don't overwrite each other's work. |
